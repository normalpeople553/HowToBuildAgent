# 零基础篇：第一次接触编程也能学习 Agent

[选择路线](README.md) · [程序员篇](developer.md) · [零基础教学模式](../agents/TEACHING-BEGINNER.md) · [English](beginner.en.md)

这条路线假设你没有写过程序，也不要求你先系统学完 Python。目标是先补齐运行 Agent 必需的最小知识，再用真实 DeepSeek API 看见一次完整的模型—工具闭环。

## 先建立正确预期

- 你不需要安装本地大模型；教程默认调用在线 `deepseek-v4-pro`。
- 你需要在自己的电脑上输入少量命令、阅读短代码，并逐步修改小片段。
- 真实 API 调用可能计费，也会把示例输入发送给服务商。
- 不要把 API Key 发到聊天里、写入代码或提交到 Git。

## 课前路线：只学马上会用到的内容

| 课次 | 学什么 | 通过标准 |
|---|---|---|
| B00 | 终端、命令、当前目录 | 能打开终端，用 `pwd` 和 `cd` 进入仓库，并说出命令在哪个目录执行 |
| B01 | 文件、目录、环境变量和虚拟环境 | 能解释代码文件、依赖、`.venv` 与 `DEEPSEEK_API_KEY` 分别是什么 |
| B02 | Python 的变量、列表、字典、函数和异常 | 能阅读教程中的短函数，并在不暴露 Key 的情况下修改一个普通参数 |
| B03 | JSON、HTTP 请求、API 与响应 | 能指出请求里的模型、消息、工具定义，以及响应里的工具请求 |
| B04 | 普通模型调用与 Agent 循环 | 能画出“用户 → 模型 → 工具 → 模型 → 回答”，并标明真正执行工具的是程序 |

这些课不要求背语法。每个概念都应在仓库真实代码中出现后再学习；暂时用不到的面向对象、算法和框架可以以后再学。

### B00：先知道命令在哪里运行

终端是用文字操作电脑的窗口；命令只会在“当前目录”找到相对路径。先运行：

```bash
pwd
ls
cd HowToBuildAgent
pwd
```

`pwd` 显示当前目录，`ls` 显示目录里的内容，`cd` 切换目录。通过标准不是记住拼写，而是能在运行安装命令前确认自己位于 `HowToBuildAgent`。

### B01：区分代码、依赖、虚拟环境和 Key

- 代码文件描述程序做什么；`tutorial/src/mini_agent/` 是本项目的主要示例源码。
- 依赖是代码使用的外部软件包，`pip install` 负责安装它们。
- `.venv` 是只服务当前项目的 Python 环境，避免不同项目的依赖互相影响。
- `DEEPSEEK_API_KEY` 是服务商识别调用者的秘密凭据。环境变量让程序读取它，而不必把它写进源码。

只检查“是否设置”，不要打印 Key 本身：

```bash
test -n "$DEEPSEEK_API_KEY" && echo "已设置" || echo "未设置"
```

### B02：只学读代码所需的 Python

先读这个函数，不需要背语法：

```python
def get_weather(city):
    result = {"city": city, "temperature": 22}
    return result
```

`city` 是输入，`result` 是一个保存键和值的字典，`return` 把结果交还给调用者。你应当能够预测 `get_weather("北京")` 返回什么，并把温度改成另一个教学数值。真实项目还会用列表保存多条消息，用异常表示操作无法正常完成。

### B03：把 API 看成一次有格式的问答

程序通过 HTTP 向服务地址发送请求；JSON 是请求和响应常用的文本结构。下面是帮助理解结构的精简示意，不是可直接执行的完整请求：

```json
{
  "model": "deepseek-v4-pro",
  "messages": [{"role": "user", "content": "北京天气如何？"}],
  "tools": [{"name": "get_weather"}]
}
```

你需要能指出：调用哪个模型、用户说了什么、程序向模型公开了哪个工具。模型返回工具请求只代表“建议调用”；程序仍要校验名称和参数。

### B04：模型不会自己执行本地函数

最小 Agent 循环是：

```text
把用户消息和工具说明发给模型
如果模型给出最终回答：停止
如果模型请求工具：程序校验并执行工具
把工具结果追加到消息，再询问模型
```

模型负责生成回答或提出工具请求；Agent 程序负责循环、校验、执行和停止。能够画出这条轨迹后，再进入真实运行。

## 第一次运行

在 macOS 或 Linux 终端依次执行；每执行一行，都先确认当前目录和命令作用：

```bash
git clone https://github.com/normalpeople553/HowToBuildAgent.git
cd HowToBuildAgent
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e tutorial
export DEEPSEEK_API_KEY="你的 DeepSeek API Key"
mini-agent-demo
```

不要盲目复制报错后的新命令。先记录：执行了哪一行、所在目录、报错最后一段，以及 Python 版本；Key 必须删掉或遮住。Windows 命令、预期输出和排障入口见[第 00 课](../docs/00-开始前先看这页.md)。

## 零基础学习规则

1. 每次只学习一个概念，并立即在代码或输出中找到它。
2. 不用“看懂了”作为完成标准；要能指出、预测、运行或解释。
3. 遇到陌生词先用一句白话解释，再引入英文术语。
4. 不要求一次写完整 Agent；先修改一个参数、一个工具或一个判断。
5. 完成 B00–B04 后，后续验收逐渐与程序员路线一致。

如果希望由 Agent 带着学，使用[零基础教学模式](../agents/TEACHING-BEGINNER.md)。
