# Human Guide: Choose Your Track

[Home](../README.en.md) · [Agent Guide](../agents/README.en.md) · [Teaching Mode](../agents/TEACHING.en.md) · [中文](README.md)

Choose the track that matches your current background. Both tracks lead to the same Agent principles and safety boundaries.

| Track | For whom | Start |
|---|---|---|
| [Complete Beginner](beginner.en.md) | No programming, terminal, Python, JSON, or API experience | Learn only the prerequisites needed to run the first Agent |
| [Developer](developer.en.md) | Can run and modify code and understands functions, data structures, and exceptions | Start from the live model–tool loop and source code |

If unsure, begin with the Complete Beginner track. You may switch after passing its prerequisite checks.

To learn with an Agent, ask it to read `AGENTS.md` and `agents/TEACHING.en.md`, recommend a track with its reason, wait for your confirmation, and then follow the corresponding teaching guide one concept at a time.
