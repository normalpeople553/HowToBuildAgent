# 人类篇：先选择你的路线

[项目首页](../README.md) · [Agent 篇](../agents/README.md) · [教学模式](../agents/TEACHING.md) · [English](README.en.md)

人类篇不假设所有读者都有相同基础。先选择与你现在的能力相符的路线；两条路线最终都会学习同一套 Agent 核心原理和安全边界。

| 路线 | 适合谁 | 从哪里开始 |
|---|---|---|
| [零基础篇](beginner.md) | 完全不了解编程，不熟悉终端、Python、JSON 或 API | 先学最小编程前置知识，再运行第一个 Agent |
| [程序员篇](developer.md) | 能独立运行和修改代码，理解函数、数据结构与异常 | 直接从真实模型—工具闭环和源码开始 |

如果你不确定，选择零基础篇。完成其中的课前检查后，可以随时切换到程序员篇，不需要重新学习已经掌握的内容。

## 让 Agent 教你

把仓库地址和下面这段话交给能够读取仓库的 Agent：

> 请读取仓库根目录 `AGENTS.md` 和 `agents/TEACHING.md`，先判断我适合零基础路线还是程序员路线，并告诉我判断依据。得到我的确认后，读取对应教学文件进入教学模式。一次只推进一个知识点，先让我预测和动手，再给提示与反馈，不要替我完成练习。

你也可以直接指定：

- “我是编程零基础，请按零基础路线开始教学。”
- “我是程序员，请按程序员路线开始教学。”

Agent 教学的分流、验收和进度规则见[教学模式](../agents/TEACHING.md)。

## 两条路线共同的最终目标

学完后，你应当能够独立解释、实现和检查：

- 模型、Agent 循环、工具和业务系统各自负责什么；
- 工具 Schema、参数校验、权限校验为什么不是一回事；
- 工具请求与结果如何通过调用 ID 配对；
- 状态、消息历史、摘要、记忆和检索如何分层；
- 怎样限制轮数、重试、输出、费用和副作用；
- 怎样区分本地测试、固定轨迹测试和真实 API 验证。
