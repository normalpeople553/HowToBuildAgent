# Agent 说明书

中文 · [English](README.en.md)

从一次模型调用出发，学会构建可控、可测试、能连接真实工具的 Agent。本仓库面向想入门 Agent 开发的人；模型的准确型号、参数、价格与真实调用源码，继续由 **[模型说明书](https://github.com/normalpeople553/HowToCallLLM)** 维护。

## 从这里开始

| 你现在的状态 | 阅读入口 |
|---|---|
| 还没有成功调用过模型 | 先用[模型说明书](https://github.com/normalpeople553/HowToCallLLM)跑通一次调用 |
| 已经会发送 `messages` 并读取回复 | 开始[《从模型调用到第一个 Agent》](docs/01-从模型调用到第一个Agent.md) |
| 已经会工具调用 | 按下方路线继续扩展；未完成章节会明确标记 |

## 两个仓库的边界

- **Agent 说明书**：讲 Agent 循环、工具、状态、记忆、检索、权限、测试和部署。
- **模型说明书**：讲某个准确模型怎么调用，维护厂商文档、参数解释和调用源码。
- **给编程 Agent 的接入规范**：仍放在模型说明书的 [Agent 接入规范](https://github.com/normalpeople553/HowToCallLLM/tree/main/agents)中，它不是人类学习 Agent 开发的教程。
